USER ENDPOINTS (Authentifié):
  POST   /api/kyc/submit              - Soumettre KYC
  GET    /api/kyc/status              - Obtenir statut
  GET    /api/kyc/{id}                - Voir détails
  GET    /api/kyc/pending             - Lister en attente

ADMIN ENDPOINTS (Super Admin):
  GET    /api/admin/kyc               - Lister tous
  GET    /api/admin/kyc/{id}          - Détails complets
  POST   /api/admin/kyc/{id}/approve  - Approuver
  POST   /api/admin/kyc/{id}/reject   - Rejetter
  GET    /api/admin/kyc-stats         - Statistiques

1. Migrer la base de données:
   cd SmallPay_backend
   php artisan migrate

2. Configurer les emails dans .env:
   MAIL_MAILER=smtp
   MAIL_HOST=smtp.xxx.com
   MAIL_FROM_ADDRESS=noreply@smallpay.com

3. Démarrer le serveur:
   php artisan serve

4. Tester l'API:
   curl -X POST http://localhost:8000/api/kyc/submit \
     -H "Authorization: Bearer TOKEN"

Voir QUICK_START_KYC.md pour plus de détails
